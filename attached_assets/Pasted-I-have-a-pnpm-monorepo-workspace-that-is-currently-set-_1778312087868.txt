Completely delete the following directories from the root of the project:
- `lib/db/`
- `lib/api-spec/`
- `lib/api-zod/`
- `lib/api-client-react/`

### Step 2: Update `pnpm-workspace.yaml`
In the root `pnpm-workspace.yaml` file:
1. Remove `drizzle-orm` from the `catalog:` list.
2. Remove `"@esbuild-kit/esm-loader"` from the `overrides:` list (this was for drizzle-kit).
3. If there are any `lib/*` packages left in the `packages:` array that no longer exist, remove their references.

### Step 3: Update Frontend `package.json`
In `artifacts/mmh-contractor/package.json`:
1. Remove any dependencies or devDependencies referencing local backend workspace packages (e.g., `@workspace/db`, `@workspace/api-client-react`, `@workspace/api-zod`).

Scan the source code inside `artifacts/mmh-contractor/src/` and do the following:

3. Find any custom fetch calls pointing to `/api/...` endpoints and remove them. 
4. If the UI relies on data from these removed API calls, temporarily replace them with hardcoded static JSON data or remove the components if they are no longer needed.

Once the cleanup is done, run the following commands to ensure everything is working:
1. Run `pnpm install` at the root to clean up the lockfile.
